Sign in

This editor publishes straight to your website. It needs a GitHub access token that can only change this one repository. The token is kept in this browser only.

How to get a token
  1. Open github.com/settings/personal-access-tokens/new while signed in to GitHub.
  2. Name it Site editor and pick an expiry date, up to a year.
  3. Under Repository access, choose Only select repositories and pick karenedegware.
  4. Under Permissions, open Repository permissions and set Contents to Read and write.
  5. Click Generate token, copy it, and paste it above.
